# Governance

Patchbay is an early-stage open-source community project.

The repository owner acts as initial maintainer and is responsible for releases, security coordination and project direction. Contributors participate through issues and pull requests.

Changes to the plugin API, manifest schema, runtime security model, compatibility policy or governance should be discussed in an issue or design proposal before implementation.

As the contributor base grows, the project may introduce a maintainer team, documented consensus process, release managers and a plugin API working group.
